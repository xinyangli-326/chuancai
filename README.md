# 川味小厨房 · Sichuan Flavor Kitchen

面向**来华留学生**的川菜文化学习网站，用于**国际中文教育**的文化教学。
学生在网上"做一道川菜"：选菜 → 备菜（认识蔬菜、肉类、调料名称）→ 上灶模拟烹饪（火候、下锅顺序、翻炒、勾芡、淋油）→ 出锅打分 → 词汇与小测。

全站中 / 拼音 / 英文三语对照，可一键开关；点击任意中文都能朗读。

## 适合谁用

- 来华留学生（HSK 2–4 左右即可上手，有拼音和英文兜底）
- 国际中文教育的文化课、口语课、综合课教师
- 对中国饮食文化感兴趣的任何人

## 六个板块

| 板块 | 内容 | 教学功能 |
| --- | --- | --- |
| 首页 · 文化 | 川菜是什么、地理气候、麻辣由来、时间轴、味型转盘、三大流派、盖碗茶 | 文化导入 |
| 选菜 · 点菜 | 8 道菜（麻婆豆腐、宫保鸡丁、回锅肉、鱼香肉丝、水煮牛肉、担担面、夫妻肺片、干煸四季豆） | 词汇预热、难度分级 |
| 备菜 · 砧板 | 食材配对处理方式（切块/切片/切丝/剁末/焯水/上浆…），支持拖拽 | 名词 + 动词 + "把"字句 |
| 烹饪 · 上灶 | 选火候、排下锅顺序、调味道、翻炒小游戏、计时、出锅打分 | 顺序表达、火候词汇 |
| 词汇 · 语言 | 7 类词汇卡（翻面看拼音英文）、8 组句型、厨具与味道词 | 词汇与语法 |
| 小测 · 闯关 | 文化选择、听音选词、厨房顺序题，共 12 题 | 形成性评价 |

另有：熊猫助手"胖达"全程提示、音效与火焰动画、徽章系统、可打印的结业证书（记录保存在浏览器本地）。

## 教学建议（1 课时 / 45 分钟）

1. **导入 10 分钟**：首页时间轴 + 味型转盘，先问"你觉得川菜只有辣吗？"
2. **备菜 15 分钟**：分组比赛，哪组先备齐食材；强调"把 + 名词 + 动词 + 结果"。
3. **上灶 20 分钟**：每组选一道菜，轮流上台选火候、按翻炒；错选的提示正好是讲解点。
4. **收尾 5 分钟**：小测 + 生成证书。

语言点：把字句、先……然后……最后、越……越……、有点儿 / 太……了、量词（勺、碗、根、瓣）。

## 内容依据（写实原则）

菜谱用量与工序、文化史实均参考公开资料整理，主要来源包括：

- 菜谱站：下厨房、豆果美食、美食天下、百度经验（如"油温六成热"约 140–180 ℃）
- 媒体与地方志类文章：澎湃新闻、网易、新浪、搜狐、腾讯新闻、简书、观察者网风闻、学术之家

其中：

- 担担面 1841 年由自贡小贩陈包包创制 —— 据《成都通览》记载（另有一说起源川东达州一带，文中已标明）
- 回锅肉"一煮二炒三回锅"与"灯盏窝"、二刀肉
- 麻婆豆腐：同治元年（1862 年）成都万福桥"陈兴盛饭铺"、陈刘氏，传统用牛肉末，分次勾芡
- 宫保鸡丁：光绪年间丁宝桢（太子少保，尊称"宫保"）家厨所创，糊辣荔枝味，糖醋约 1 : 1.5
- 水煮牛肉：相传北宋时期自贡盐场役牛，盐工以盐水加花椒辣椒煮食
- 夫妻肺片：20 世纪 30 年代郭朝华、张田政夫妇在成都长顺街摆摊，现主料为牛头皮、牛心、牛舌、牛肚（已不含牛肺）
- 郫县豆瓣：相传清康熙年间（约 1688 年）陈逸仙携蚕豆入蜀；咸丰三年（1853 年）陈守信开设"益丰和"酱园
- 四季豆含皂甙与红细胞凝集素，必须彻底加热熟透

历史传说说法不一的地方，文中统一用"相传""据记载"标明，方便课堂讨论。

## 技术说明

- 纯静态站点：`index.html` + `assets/css/style.css` + `assets/js/*.js`，**零外部依赖**，不需要联网、不需要构建，教室断网也能用。
- 朗读使用浏览器内置的语音合成（Edge / Chrome 效果最好）。
- 音效用 WebAudio 现场合成，没有任何音频文件。
- 学习记录存在浏览器 `localStorage`，不上传任何数据。

## 本地运行

直接双击 `index.html` 即可；或用任意静态服务器：

```bash
python -m http.server 8080
# 然后打开 http://127.0.0.1:8080
```

## 发布到 GitHub Pages

1. 双击 `一键发布到GitHub.bat`（在上一级目录），按提示输入 GitHub 用户名和仓库名；
2. 首次推送会弹出浏览器让你登录 GitHub；
3. 打开 `https://github.com/<用户名>/<仓库名>/settings/pages`，
   Source 选 `Deploy from a branch`，Branch 选 `main` + `/ (root)`，保存；
4. 一两分钟后访问 `https://<用户名>.github.io/<仓库名>/`。
